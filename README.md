## 🚀 How to Import Any Blueprint

### Method 1: One-Click Import (My Home Assistant)
Click any **Import** badge in the table above to open your Home Assistant instance with the blueprint pre-filled.

### Method 2: Manual Import
1. In Home Assistant, navigate to **Settings** > **Automations & Scenes** > **Blueprints**.
2. Click **Import Blueprint** (bottom right).
3. Paste the URL of any `.yaml` blueprint file in this repository and click **Import Blueprint**.
